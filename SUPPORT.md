# Vibe Coding Control support

For connection problems, OAuth revocation, account access or data questions,
email **dimoncheck2020@gmail.com** (the service contact also published in
[VCC Terms, section 9](https://vibecodingcontrol.com/terms#en)).

For public package bugs, open an issue at
https://github.com/OMNOM-111/vcc-remote/issues.

Include the client name/version, the failed step and a redacted error message.
Never post access/refresh tokens, passwords, cookies, project history, private
project IDs or personal data in a public issue. Send account questions privately.

Disconnect an OAuth application at https://vibecodingcontrol.com/mcp/connections.
The existing local Connector is managed separately in VCC Settings.
